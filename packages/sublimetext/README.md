# @dabzse/omnigit-sublimetext — OmniGit for Sublime Text (3 & 4)

> Universal Git Graph visualization and GitLens-style productivity package for **Sublime Text 3 & 4**.

---

## ⚡ Features

- **GitLens-Style Minihtml Phantoms**: Displays author, commit short-hash, and summary inline at the cursor line.
- **Interactive Git Graph**: Command `OmniGit: Show Git Graph` (`Ctrl+Alt+G`) launches the OmniGit webview interface.
- **Commands & Keybindings**:
  - `Ctrl+Alt+G`: `omnigit_show_graph`
  - `Ctrl+Alt+B`: `omnigit_toggle_blame`

---

## 📦 Installation

Copy or symlink `packages/sublimetext` into your Sublime Text `Packages` directory:

- **Linux**: `~/.config/sublime-text/Packages/OmniGit/`
- **macOS**: `~/Library/Application Support/Sublime Text/Packages/OmniGit/`
- **Windows**: `%APPDATA%\Sublime Text\Packages\OmniGit\`
